# Código de Conducta 🤝

## Nuestro Compromiso

Nos comprometemos a hacer de este proyecto un espacio inclusivo y respetuoso para todas las personas, independientemente de su nivel de experiencia, origen o identidad.

## Estándares del Proyecto

Para mantener un buen ambiente de trabajo:

- **Empatía y respeto:** Tratarnos de forma respetuosa y escuchar las ideas de todos.
- **Críticas constructivas:** Enfocarnos en mejorar el código y el proyecto de forma positiva.
- **Colaboración activa:** Buena predisposición para ayudar y aprender conjuntamente.

Comportamientos como el lenguaje despectivo, descalificaciones o comentarios inapropiados no serán tolerados en ningún espacio del repositorio (Issues, Pull Requests o chats de trabajo).
